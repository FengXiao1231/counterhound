`Format` and `InternationalString` no longer change the stored duration. Each now works on a local copy, `dur := d.duration`, and negates that copy for negative inputs, so repeated calls give the same output and `Duration()` stays negative. The repro now passes. I didn't run the project's other tests, and I didn't add a regression test.

I changed `InternationalString` too because it had the same in-place negation as `Format`.
