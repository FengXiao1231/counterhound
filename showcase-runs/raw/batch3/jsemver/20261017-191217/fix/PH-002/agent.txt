I changed `compareIdentifiers` in `Version.java` so that when exactly one identifier is numeric, the numeric one always ranks lower, as SemVer item 11 requires. It also treats `"0"` as numeric, since `isNumeric` rejects it. Because of that, `1.0.0-1` vs `1.0.0--a` and `1.0.0-0` vs `1.0.0--x` now compare correctly. I left `isNumeric` itself alone because the increment code also calls it. The repro test passes; I didn't run any other existing tests or add a regression test.
