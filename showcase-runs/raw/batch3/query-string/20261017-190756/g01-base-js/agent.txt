I tested 8 properties and reported 1 bug: `stringifyUrl` turns an existing index-format array in the URL's query into `a=[object Object]`.

For `stringifyUrl({url: 'https://foo.bar?a[0]=x&a[1]=y', query: {}}, {arrayFormat: 'index', encode: false})`, the repro file `repro_index_nosort.test.mjs` fails with exactly that output. The cause is that `stringifyUrl` parses the existing query with `sort: false`, and `parse` only turns index-keyed objects into arrays when sorting is on.
