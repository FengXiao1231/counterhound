I changed `parse_paisa` in `num2words/lang_BN.py` to build the paisa value as `(paisa_str + '00')[:2]` instead of `str(int(paisa_str) * 100)[:2]`. Converting to an integer dropped the leading zero, so `0.01` was read as 10 paisa. Now `0.01` gives 01, and fractions like `.5` or `.50` still give 50. The repro test passes. I didn't run the existing Bengali tests or add a regression test.
